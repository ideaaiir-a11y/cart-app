     6→     6→
     7→     7→- `POST /api/jobs` — multipart: `inputs`(JSON string[]), `files`(File[]), `watermarkText`, `watermarkMode`(text|logo), `watermarkPos`, `watermarkLogo`(dataURL string), `useExternal`(0/1), `assistantUrl`, `assistantKey`, `assistantModel` → `{ok, jobId}`
     8→     8→- `POST /api/jobs/{id}/run` → `{ok}` (پایپ‌لاین در پس‌زمینه اجرا می‌شود)
     9→     9→- `GET /api/jobs/{id}` → `{ok, job:{id,status,currentStage,stages:[{key,title,status,logs[],startedAt,endedAt}],error,watermarkText,cards:[CardData]}}` — برای polling هر ۲ ثانیه
    10→    10→- `GET /api/jobs/{id}/download` → ZIP همه کارت‌های done
    11→    11→- `GET /api/jobs/{id}/download/{cardId}` → فایل HTML تکی
    12→    12→- `DELETE /api/jobs/{id}` → حذف job
    13→    13→- `POST /api/cards/{cardId}` — JSON: `{name?, description?, usage?, price? (عدد تومان), specs?}` → `{ok, card}` (HTML دوباره رندر می‌شود)
    14→    14→- `POST /api/assistant/chat` — JSON: `{sessionId, cardId?, message}` → `{ok, reply, applied: bool, card?}` — چت‌بات ویرایشگر
    15→    15→- `GET /api/settings` → `{ok, settings:{watermarkText, watermarkMode, watermarkPos, assistantUrl, assistantKey, assistantModel, useExternal, baleTokenSet}}`
    16→    16→- `POST /api/settings` — JSON همان فیلدها → `{ok}`
    17→    17→- `POST /api/bale/setup` — JSON `{token}` → تست getMe + setWebhook روی tapi.bale.ai → `{ok, info?, error?}`
    18→    18→- `POST /api/bale/hook` — وب‌هوک دریافت آپدیت بله (پیام → پاسخ LLM → sendMessage + لاگ) → `{ok}`
    19→    19→- `GET /api/bale/status` → `{ok, tokenSet, lastInfo?, chatSet, notify}`
    20→    20→- `GET /api/bale/logs?limit=30` → `{ok, logs:[{id,direction,chatId,userName,text,ok,error,createdAt}]}` — آخرین پیام‌های ربات
    21→    21→- `DELETE /api/bale/logs` → `{ok}` — پاک کردن همه لاگ‌ها
    22→    22→- `POST /api/bale/test` — JSON `{text?}` → ارسال پیام آزمایشی به چت ثبت‌شده + لاگ → `{ok}` یا خطای API بله
    23→    23→- `POST /api/jobs/bulk-delete` — JSON `{ids:string[]}` → `{ok, deleted}` (کارت‌ها Cascade)
    24→    24→- `POST /api/jobs/{id}/rerun` → ریست مراحل/کارت‌ها + اجرای مجدد پایپ‌لاین در پس‌زمینه → `{ok}`
    25→    25→- `GET /api/cards/{cardId}/share` → صفحه HTML عمومی کارت + متاتگ og/twitter + JSON-LD Product + نوار برند (text/html)
    26→    26→- `GET /api/cards/{cardId}/qr` → تصویر PNG کد QR لینک اشتراک (هدر x-share-url)
    27→    27→- `POST /api/cards/{cardId}/translate` → ترجمه محتوا به انگلیسی با LLM + ذخیره descriptionEn/usageEn/specsEn/nameEn + رندر htmlEn چپ‌به‌راست → `{ok, card:{id,nameEn,descriptionEn,usageEn,specsEn,htmlEn}}`
    28→    28→- `GET /api/jobs/{id}/download/{cardId}?lang=en` → فایل HTML نسخه انگلیسی (اگر htmlEn خالی باشد ۴۰۹ با پیام فارسی)
    29→    29→- `GET /api/jobs/{id}/download` → ZIP حالا شامل «-en.html» برای کارت‌های ترجمه‌شده هم هست
    30→    30→- `GET /api/jobs` → هر job حالا `hasEn` هم دارد (برای badge EN در UI)
    31→    31→- هر card در `GET /api/jobs/{id}` → `hasEn: boolean` (وجود نسخه انگلیسی)
